# Aya-reminder

用自然语言设置定时提醒! 忘掉crontab

## 指令
```
@bot 提醒我 明天下午3点 交周报     单次提醒
@bot 半小时后 开会               相对时间
@bot 每天18:30 喂猫             循环提醒
@bot 每周五 20:00 公会战
@bot 每周一三五 8:00 上班
@bot 工作日 8:00 起床
@bot 每月1号 9:00 发工资
```

- 无空格也可以：`提醒我明天下午3点交周报`、`每天18:30喂猫`
- 解析后回显识别结果，回复「**确认**」生效、「**取消**」放弃（3 分钟内有效）
- 数字支持阿拉伯（18:30）和中文（下午三点十五分）
  
## 管理

| 指令 | 说明 |
|---|---|
| `我的提醒` | 查看自己的提醒 |
| `本群提醒` | 群管理员查看全群提醒 |
| `取消提醒 编号` | 删除（本人可删自己的，群管理员可删任何人的） |
| `提醒帮助` | 显示帮助 |

## 限额与保护

- 每人每场景 5 条，每群总共 20 条
- 提醒内容最长 128 字
- bot 重启时：单次提醒若错过后 10 分钟内会补发，超时自动清除；循环提醒跳过错过的点位
